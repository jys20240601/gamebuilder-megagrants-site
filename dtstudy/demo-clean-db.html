메시지 9통이 DB에 들어가기까지

가상 부산항 터미널에서 5초 동안 들어온 MQTT 메시지 9통을, Python 저장기가 정제 → 정합 → 저장하는 과정입니다. 단계를 눌러 보세요.

다섯 가지 원칙
  1. 원본은 지우지 않는다. 규칙을 바꾸면 원본으로 다시 정제할 수 있어야 한다.
  2. 지우기보다 표시한다. 튀는 값은 quality 칸에 표시하고, 분석할 때 걸러 쓴다.
  3. 시간은 UTC로 저장한다. 한국 시간은 화면에 보여 줄 때만 바꾼다.
  4. 장비 대장이 정합의 중심이다. 센서 ID, 3D 물체 이름, 위치, 단위, 정상 범위를 한 표에 둔다.
  5. 규칙은 코드가 아니라 표로 관리한다. 장비를 추가할 때 대장에 한 줄만 넣으면 된다.
