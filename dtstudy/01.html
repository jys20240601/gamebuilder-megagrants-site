과정 언리얼 기반 디지털 트윈 시스템 개발자 양성과정 (KDT). 1차 서면 심사 통과, 2차 인터뷰 심사
교육기관 데이원컴퍼니(패스트캠퍼스) B2G 교육사업부. 2026-06-01 메일로 사전 논의를 시작했다

메일 첫 줄에 "KDT 빅데이터 과정 인터뷰 심사"라고 적혀 있다. 이 과정이 KDT에서 빅데이터 분야로 접수됐다면 심사위원도 빅데이터 쪽 전문가일 수 있다(추정). 그렇다면 언리얼 시각화보다 데이터 수집, 저장, 분석 파이프라인을 설명하는 능력을 더 많이 볼 것이다. 사전미팅에서 꼭 확인한다.

1. 삼우이머션 한눈에

  • 2011년 설립, 부산 동구 본사. 산업·국방 XR 교육훈련으로 시작해 지금은 XR 훈련 + 디지털트윈 + 자체 AI의 세 축으로 사업한다. 회사 소개 문구는 "14년간 축적된 XR 콘텐츠 제작 역량"이다.
  • 2025 사업계획 문서에 나온 목표: 조직 75명에서 90명, 목표 매출 144억 원. 실적이 아니라 계획치다. 투자는 pre-A 단계(thevc 기준).
  • 내부 개발 도구는 REDMINE, GitLab, Google Workspace. 자체 개발 표준(IMDF)과 그 표준 위의 개발 도구 IMBuilder가 있고, 블루프린트를 자동으로 만드는 IMBuilder-X를 내세운다.

  • 사보에 "6개월간 진행된 KDT 프로젝트 과정에서 기획부터 개발, 심사까지 전 과정에 참여"한 기록이 있다. KDT 기업 프로젝트 운영 경험이 있다는 뜻이다.

→ 삼우이머션은 우리 과정에서 캡스톤 과제 출제, 멘토링, 심사, 채용을 맡을 수 있는 회사이고, 이미 해 본 회사다.

삼우이머션이 언리얼을 고른 이유 (Epic 스포트라이트)

  • WGS84 좌표계와 MQTT 데이터 연동을 지원한다. 지오레퍼런싱 플러그인으로 여러 좌표계를 WGS84로 통일했다.
  • 전체 소스 코드가 공개되어 데이터 통합에 유리하다.
  • 마켓플레이스 플러그인·에셋으로 개발 기간을 줄였다.
  • 다음 목표는 World Partition과 Nanite로 대규모 오픈월드 트윈으로 확장하는 것이다.

3. 삼우이머션 디지털트윈의 공통 구조

여러 사례를 겹쳐 보면 구조가 거의 같다. 인터뷰에서 "디지털트윈 시스템이 뭐냐"는 질문에 이 그림으로 답하면 된다.

[현장]  IoT 센서(온도·진동·공기질·수질·화재), GPS 추적기, 스마트 헬멧,
        AIS·레이더(선박), CCTV, 레거시 설비(PLC)
   │
[통신]  5G · MQTT · oneM2M · Modbus · HLA      ← 산업 표준 연동 허브
   │
[플랫폼] IoT 플랫폼 / 엣지 서버 / 클라우드
        수집 → 저장(이력) → 임계값 알림 → AI 진단·예측
   │
[트윈]  Unreal Engine
        지오레퍼런싱(WGS84)·Cesium, GIS(DEM·CityGML·전자해도), 3D 설비 모델
        관제 UI(알람·데이터 모니터링), 시뮬레이션
   │
[사용자] 관제실 화면, 앱, 브라우저 접속(PC·모바일)
  • 이 다섯 층에서 [통신]과 [플랫폼]이 빅데이터 부분이다. 공개 자료에는 DB나 스트림 처리 기술 이름이 나오지 않는다. 사전미팅에서 삼우이머션이 실제로 무엇을 쓰는지 물어볼 가치가 있다.
  • VARLOS의 최신 소개에는 "AI 에이전트가 해결 워크플로를 제시·실행", "자연어 기반 통합 관제"가 들어 있다. 디지털트윈에 LLM 에이전트를 붙이는 방향이다.

4. 내가 알아야 할 것

4-1. 반드시 설명할 수 있어야 하는 개념 (우선순위 순)

  1. 디지털트윈의 단계: 3D 재현 → 실시간 모니터링 → 시뮬레이션·예측 → 제어. 삼우이머션 사례는 대부분 모니터링 단계이고, 한화오션 PoC와 터미널 생산성 예측이 예측 단계에 걸친다.
  2. 데이터 파이프라인 (빅데이터 심사 대비 핵심): 수집(MQTT, OPC UA, Modbus) → 저장(시계열 DB: InfluxDB, TimescaleDB 같은 종류) → 처리(스트림, 배치) → 분석(이상탐지, 예측) → 시각화(언리얼). 단계마다 우리 과정의 어느 Stage에서 배우는지 짝지어 말할 수 있어야 한다.
  3. MQTT: 브로커, 토픽, 발행/구독, QoS. 삼우이머션의 모든 관제 사례에 나온다. 언리얼에서 MQTT를 받는 방법(플러그인 또는 Python 중계)도 한 문장으로 말할 수 있게 한다.
  4. 공간정보: WGS84, 지오레퍼런싱, Cesium for Unreal, DEM, CityGML, shapefile, 전자해도(S-57/S-63). 도시·항만 트윈의 기본이다.
  5. AIS 데이터: 선박이 위치, 속도, 침로를 주기적으로 방송하는 데이터. 양이 많고 시간과 공간이 함께 있는 대표적인 빅데이터이며, 삼우이머션 해양 사업의 핵심 데이터 소스다.
  6. 언리얼 관제 기술: UMG 관제 UI, Pixel Streaming(브라우저 접속), nDisplay(대형 관제 화면), World Partition, Nanite, Lumen, HLOD.
  7. AI 활용: 센서 이상탐지·예측, 비전(YOLO류 선박·차량 인식), sLM 에이전트 관제.

4-2. 6월 설계안과 삼우이머션 사업의 접점

6월 초안 구성(960시간): 공통기초 60h → 스마트홈 170h → 디지털트윈 도시 130h → 산업 도메인 모듈 A·B 각 110h → 기업연계 캡스톤 290h(30.2%) → 취업·포트폴리오 90h. 산업 도메인은 스마트팩토리 + ROS2 실물 로봇(AMR) 연동을 우선 권고했다.

6월 초안 삼우이머션과의 접점
Stage 1 센서 수집(MQTT), 실시간 바인딩, 관제 UI 삼우 관제 사례의 기본 구조와 같다
Stage 2 도시: GIS·포인트 클라우드, 대규모 스트림, 시계열 DB 삼우 부산 디지털트윈 과정(Cesium, 포토그래메트리), 자갈치(CityGML·DEM)와 거의 같다
산업 도메인 카탈로그: 방재·재난, 물류 자갈치(화재·침수·탈출 경로), 항만 터미널(장비 동선)과 맞닿는다
캡스톤 290h 삼우 실무 주제(항만 관제, 해양 안전, 시설 안전관리, 조선 설비 모니터링)를 과제로 받기 좋다
LLM 자연어 작업 지시(선택 과제) VARLOS의 자연어 통합 관제, OWLIX AI 방향과 같다
AI 보조 코딩 + "코드 설명 게이트" 삼우의 IMBuilder-X(블루프린트 자동 생성)처럼 개발 자동화를 지향하는 회사라 설득하기 쉽다
  • 간극: 6월 초안의 우선 도메인은 제조(공장 + 로봇)이고, 삼우이머션의 주력은 항만·조선·해양·공공시설이다. 최종 제출본이 어느 쪽으로 정리됐는지 모른다. 사전미팅에서 확인하고, 필요하면 "항만·해양 관제 도메인"을 캡스톤 주제로 넣는 안을 준비한다.
  • 내 경험 연결 소재: 국내성 디지털트윈(UE 5.8, World Partition·HLOD 대규모 월드, VR 성능을 p95 프레임 시간으로 측정)은 삼우이머션이 스포트라이트에서 밝힌 다음 목표(World Partition·Nanite 대규모 확장)와 바로 이어진다.

4-3. 사전미팅(11/16)에서 확인할 것

  1. 최종 제출 제안서 공유 요청: 과정명 변경 이유, 총 시수, Stage 구성, 장비(로봇 포함 여부), 강사 배치.
  2. 참여기업 전체 구성과 삼우이머션의 역할: 캡스톤 과제 출제, 멘토링, 심사, 채용 약정 인원.
  3. "빅데이터 과정"이라는 표현의 의미: KDT 훈련분야가 빅데이터인지.
  4. 인터뷰 형식: 발표 여부와 시간, 참석자(기관, 기업, 강사), 질문별 답변 담당.
  5. 훈련 장소와 방식(부산인지 서울인지, 대면 여부).
  6. 삼우이머션 실무에서 쓰는 데이터 스택(DB, 스트림 처리, 브라우저 배포 방식). 강의 내용을 실무와 맞추는 근거가 된다.
  7. 언리얼 MQTT 연동 방식(엔진 내장 플러그인, 외부 플러그인, 자체 C++, 중계 서버). 내장 플러그인은 아직 실험 단계라 실무 방식을 알아 두면 커리큘럼 근거가 된다(04 MQTT 3단계).

4-4. 예상 질문과 답변 방향 (강사 입장)

예상 질문 답변 방향
왜 언리얼인가? WGS84·MQTT 연동, 전체 소스 공개, Cesium 대규모 지형, 실시간 렌더링. 삼우이머션이 실제로 같은 이유로 언리얼을 골랐다(Epic 스포트라이트)
빅데이터 요소는 어디에 있나? 수집 → 저장 → 처리 → 분석 → 시각화 단계를 Stage별로 짚는다. AIS 같은 대용량 시공간 데이터, 고빈도 센서 시계열
비전공자가 6개월 안에 가능한가? 나선형 PBL(같은 패턴을 집 → 도시 → 산업으로 키움), AI 보조 코딩, 코드 설명 게이트로 이해도 검증
기업 프로젝트 30%는 어떻게 운영하나? 참여기업 실무 주제 → 기획서 → 심사 → 팀 빌딩 → 수행 → 발표. 삼우이머션은 KDT 프로젝트를 기획부터 심사까지 해 본 경험이 있다
수료생은 어디로 취업하나? XR·디지털트윈 기업(삼우이머션 등), SI, 항만·조선·제조, 공공·안전 관제
강사는 실무를 아나? 대규모 언리얼 디지털트윈 제작 경험, 성능 측정과 최적화, 강의 경력

  2. (오늘) 데이원컴퍼니에 최종 제출 제안서를 요청한다. 내일 미팅 전에 받아야 4-2의 간극을 정리할 수 있다.
  3. (사전미팅 뒤) 확정된 커리큘럼 기준으로 예상 질문 답변을 1분 분량 문장으로 다듬는다.

주의

  • 삼우이머션 정보는 대부분 회사 홈페이지, 보도자료, 사보에서 왔다. 홍보 성격이고 제3자 검증은 없다. 매출, 인원 수치는 계획치다.
  • 자갈치 R&D 원문 페이지와 한화오션 계약 공지 원문은 본문을 읽지 못했다. 같은 내용을 CAD&Graphics 기사와 영문 포트폴리오로 확인했다.
  • KDT 2차 인터뷰의 공식 평가항목은 공고문 첨부(hwpx) 안에 있어 아직 읽지 못했다. 정책 설명은 "신기술 분야 선도기업이 직접 훈련과정을 설계·운영하는 기업 맞춤형 훈련"이다. 6월 초안에는 "전체 과정의 30% 이상 기업 실전 프로젝트"가 KDT 요건으로 적혀 있다.
