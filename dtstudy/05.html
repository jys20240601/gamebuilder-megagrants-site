디지털트윈 인터뷰 노트목차

IoT(사물인터넷)의 정확한 개념

MQTT는 04 MQTT, 전체 흐름은 03 전체흐름 쉽게 참고.

정의

IoT(Internet of Things, 사물인터넷)는 사물에 센서와 통신 기능을 넣어 네트워크로 연결하고, 사람이 일일이 개입하지 않아도 사물이 스스로 상태를 감지하고, 데이터를 주고받고, 필요하면 동작하게 하는 기술과 환경이다.

  • "사물"은 센서, 장비, 차량, 설비, 건물, 사람이 착용한 기기까지 포함한다.
  • 용어는 1999년 케빈 애슈턴이 RFID로 공급망을 추적하자는 발표에서 처음 썼다.
  • 국제전기통신연합(ITU-T Y.2060, 2012)은 "기존·차세대 정보통신 기술로 물리적·가상의 사물을 서로 연결해 고도화된 서비스를 가능하게 하는 정보사회의 전 지구적 기반"으로 정의한다.

핵심은 네 동작

 감지(Sense)  →  연결(Connect)  →  판단(Analyze)  →  동작(Act)
 센서가 측정      네트워크로 전송     플랫폼·AI가 분석     장비를 제어
 온도 42.5℃      MQTT로 브로커에    40℃ 넘음 → 위험     냉각 팬 켜기

데이터를 모으기만 하면 원격 모니터링이고, 판단해서 다시 사물을 움직이면 완전한 IoT다.

구성 4계층

계층 하는 일 예
① 디바이스 감지(센서)와 구동(액추에이터) 온도·진동·GPS 센서, 스마트 헬멧, 모터, 밸브, 팬
② 네트워크 데이터를 실어 나름 Wi-Fi, 5G·LTE, 저전력 광역망(LoRa, NB-IoT), 블루투스, 유선(이더넷, RS-485)
③ 플랫폼 수집, 기기 관리, 저장, 규칙 처리 MQTT 브로커, oneM2M 플랫폼, 클라우드 IoT 서비스, DB
④ 서비스 사람이 쓰는 기능 관제 화면, 알람 앱, 분석, 디지털트윈

통신 규칙(프로토콜)은 ②와 ③ 사이에 걸친다. 대표적으로 MQTT, CoAP, HTTP가 있고, 공장 설비에는 Modbus, OPC UA가 쓰인다.

IoT에 필요한 것 전체 (MQTT는 그중 하나)

MQTT는 ②와 ③ 사이에서 "어떻게 말할지"를 정한 통신 규칙 하나다. IoT를 실제로 만들려면 계층마다 필요한 것이 있고, 모든 계층에 걸치는 보안과 운영이 따로 있다.

구분 필요한 것 예
① 디바이스 센서, 액추에이터 온도·진동·가스·GPS 센서, 카메라 / 모터, 밸브, 릴레이, 팬
두뇌 보드 아두이노, ESP32(와이파이 내장 소형 보드), 라즈베리파이, 산업용 PLC
전원 배터리, 상시 전원, PoE(랜선으로 전원 공급)
② 네트워크 근거리 무선 Wi-Fi, 블루투스(BLE), Zigbee(스마트홈 센서)
원거리 무선 LTE·5G, 저전력 광역망 LoRa·NB-IoT(배터리로 수년, 수 km)
유선 이더넷, RS-485(공장 설비 배선)
통신 규칙 기기 → 플랫폼 MQTT(실시간 스트림), HTTP·REST(가끔 보내기, 조회), CoAP(초저전력 기기용 가벼운 HTTP), WebSocket(브라우저 실시간)
산업·분야별 Modbus(옛 공장 설비), OPC UA(최신 공장 설비 표준), AIS·NMEA(선박 위치, GPS 문장 형식)
서버끼리 대용량 Kafka, AMQP(서버 사이 메시지 대량 전달)
게이트웨이·엣지 통신 방식 변환, 현장 1차 처리 Modbus를 읽어 MQTT로 발행하는 장치, 자갈치 엣지 서버
③ 플랫폼 메시지 중계 MQTT 브로커(Mosquitto, EMQX)
기기 관리 기기 등록, 인증서 발급, 상태 감시, 원격 펌웨어 업데이트(OTA), 관리 표준 LwM2M
공통 플랫폼 표준 oneM2M(국내 공공 IoT, 자갈치 사례)
저장·처리 시계열 DB(InfluxDB 등), 규칙 엔진(기준 넘으면 알람), 분석·AI
④ 서비스 사람이 쓰는 화면 대시보드(Grafana 등), 알람 앱, 언리얼 디지털트윈
보안 (전 계층) 기기·통신·접근 보호 기기 인증(계정, 인증서), TLS 암호화, 토픽·데이터 접근 권한, 펌웨어 보안 업데이트, 망 분리
운영 (전 계층) 오래 안정적으로 돌리기 시간 동기화(NTP, 시간 정합의 전제), 끊긴 기기 감시(Last Will), 배터리·통신 상태 점검, 장애 알림

과정 실습 키트로 줄이면

계층 실습 구성
디바이스 라즈베리파이 또는 ESP32 + 온도 센서 + 팬(릴레이). 6월 설계안의 ROS2 로봇도 디바이스 계층
네트워크·통신 교실 Wi-Fi + MQTT, 비교용 HTTP
플랫폼 Mosquitto + Python 저장기 + 시계열 DB
서비스 언리얼 디지털트윈 관제 화면
보안·운영 계정·TLS 설정, Last Will로 끊김 감지, NTP 시간 맞추기

인터뷰용: "IoT는 센서, 통신, 플랫폼, 서비스에 보안과 운영까지 갖춰야 돌아가고, MQTT는 그중 통신 규칙 하나입니다. 과정은 센서 보드부터 언리얼 관제 화면까지 한 줄로 이어지는 키트로 전체를 직접 만들어 봅니다."

같이 알아야 할 용어

용어 뜻
M2M 기계끼리 1:1로 직접 통신하는 것. IoT는 이것을 인터넷 규모, 다대다, 플랫폼과 데이터 중심으로 넓힌 개념이다
IIoT(산업용 IoT) 공장, 항만, 플랜트의 IoT. 신뢰성, 옛 설비 프로토콜(Modbus, OPC UA), 보안이 더 중요하다
엣지 컴퓨팅 데이터를 클라우드로 다 보내기 전에 현장 가까이에서 먼저 모으고 처리하는 것. 자갈치시장의 멀티 프로토콜 엣지 서버가 예
oneM2M 한국 TTA를 포함한 여러 나라 표준화 기구가 만든 IoT 공통 플랫폼 표준. 국내 공공 IoT에서 많이 쓴다(오픈소스 구현 예: KETI의 Mobius). 자갈치시장 사례가 이 표준을 따랐다
게이트웨이 서로 다른 통신 방식을 바꿔 주는 중계 장치. 예: Modbus 설비 값을 읽어 MQTT로 발행

흔한 오해

  • "인터넷"이라고 꼭 공용 인터넷에 붙는 것은 아니다. 공장 내부망, 항만 전용망 안에서만 돌아도 IoT다.
  • IoT는 스마트홈 가전만 뜻하지 않는다. 산업 현장이 더 큰 시장이다.
  • IoT는 기기 하나가 아니라 체계다. 센서만 달아 놓고 데이터를 모으고 쓰는 구조가 없으면 IoT라고 하기 어렵다.

예시

분야 예
일상 앱으로 켜는 에어컨, 스마트워치 심박 측정, 공유 킥보드 GPS
농업 스마트팜 온습도 센서와 자동 환기
삼우이머션 사례 부산항 터미널: 장비 GPS(1초 5회), 스마트 헬멧·워치(위치, 생체신호), 지능형 CCTV / 자갈치시장: 수질·침수·유해가스·화재 센서를 5G로 oneM2M 서버에 연결

IoT, 빅데이터, 디지털트윈의 관계

 IoT              →   빅데이터            →   디지털트윈
 현장의 감각과 손발      쏟아지는 데이터 가공       3D로 재현·분석·시뮬레이션
 (센서, 통신, 제어)     (정제, 정합, 저장, 분석)    (관제, 예측, 원격 제어)
  • IoT가 없으면 디지털트윈은 움직이지 않는 3D 모델일 뿐이다.
  • 디지털트윈이 없으면 IoT 데이터는 숫자 표로만 남는다.
  • 그 사이에서 데이터를 쓸 수 있게 만드는 일이 빅데이터 가공이다.

인터뷰용 한 문단

"IoT는 사물에 센서와 통신을 넣어 사람 개입 없이 감지, 연결, 판단, 동작하게 하는 체계입니다. 디바이스, 네트워크, 플랫폼, 서비스 네 계층으로 이루어지고, 디지털트윈은 그중 서비스 계층에서 IoT 데이터를 3D로 재현하고 분석하는 역할입니다. 우리 과정은 IoT로 현장 데이터를 모으고, 빅데이터로 가공하고, 언리얼 디지털트윈으로 보여 주고 제어하는 흐름 전체를 다룹니다."
