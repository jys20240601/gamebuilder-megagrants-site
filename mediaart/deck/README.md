# 미디어아트 3작품 · 3D 작품 소개

ONE WAVE, 포털 진입, 달을 품은 항아리를 소개하는 12장 발표자료입니다. 작품 의도와 문구, 발표 메모는 기존 12장 소개 자료를 따릅니다. 각 작품을 실제로 조작하며 장면을 천천히 감상할 수 있습니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 열거나 `serve.bat`을 실행하고 http://127.0.0.1:8123/3d/ 를 엽니다. 스크립트, 폰트, 텍스처, 작품 영상은 모두 로컬 파일이며 실행 중 외부 요청을 보내지 않습니다. WebGL2를 지원하지 않거나 컨텍스트를 잃으면 기존 2D 자료로 이동합니다. 게시본의 대체 페이지는 `/mediaart/`입니다.

## 조작

| 조작 | 기능 |
| --- | --- |
| ← / →, PgUp / PgDn, Home / End | 슬라이드 이동 |
| O / N / F / B / Esc | 목차 / 발표 메모 / 전체화면 / 검은 화면 / 닫기 |
| Space | ONE WAVE 3·5장 물살, 4장 재생·정지, 다른 장 다음 슬라이드 |
| R | 현재 작품 장면 다시 보기 |
| 작품 이름 · 카드 · 개요의 작품 | 해당 작품으로 이동 |
| 3장 PRESS 또는 수조 클릭 | 링에 물살 보내기 |
| 4장 리본 · 시간 막대 · 장면 스틸 | 60초 장면의 시점 변경 |
| 5장 같은 규칙으로 다시 | 새로운 링의 움직임과 안착을 감상 |
| 7장 해 고도 · 세로 드래그 · 인물 드래그 | 그림자를 판정선에 맞추기 |
| 8장 다시 걷기 | 문턱을 넘는 장면 감상 |
| 10장 위상 막대 · 다이얼 · 가로 드래그 · 단계 버튼 | 항아리에 드리운 그림자 이동 |
| 11장 그림자 · 안개 · 바람 | 작은 움직임 강조 선택 |

각 작품 첫 장의 영상 버튼은 실제 작품 영상을 모달에서 재생합니다. `#1`부터 `#12`까지 바로 연결할 수 있습니다. 도구 막대는 잠시 조작하지 않으면 숨고, 포인터 이동이나 키 입력으로 다시 나타납니다.

시스템의 동작 줄이기 설정 또는 `?still`은 카메라 이동과 자동 연출을 줄입니다. `?2d`는 대체 소개 자료로 바로 이동합니다. 슬라이드는 1600×900 무대에 맞춰 창에 비례 축소됩니다.

## 빌드와 검증

프로젝트 루트에서 `python -B deck/3d/tools/build_3d.py`를 실행합니다. `deck/src/deck.html`의 12장 문구와 메모를 읽고, 화면 및 JavaScript에서 사용한 문자로 NanumSquare Neo 글꼴을 부분집합 처리해 `deck/3d/index.html`에 넣습니다. `fontTools`가 필요합니다. 기존 2D 작성 도구를 실행하거나 기존 발표 파일을 변경하지 않습니다.

three.js r170 고정본은 `tools/vendor_three.py`, 영상과 텍스처는 `tools/prep_assets.py`가 준비합니다. 이미 포함된 자산으로는 이 두 단계를 다시 실행할 필요가 없습니다. 검증 결과와 스크린샷은 `validation/`에 기록하며 게시 대상에 포함하지 않습니다.

게시 시 `tools/deploy_deck.py`만 사용합니다. 게시 저장소의 `mediaart/deck/`만 갱신하고, 일반 push 직전에 `git pull --rebase`를 실행합니다. `web/tools/deploy_pages.py`는 다른 작업자의 `mediaart/` 파일에 영향을 줄 수 있으므로 이 발표자료 게시에 사용하지 않습니다.
