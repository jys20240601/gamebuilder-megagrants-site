개인정보처리방침

어느별 스튜디오 · 시행일 2026년 11월 7일

이 방침은 어느별 스튜디오(이하 “스튜디오”)가 업무용으로 직접 운영하는 내부 도구에 적용됩니다. 예를 들어 작업 컴퓨터의 파일을 스튜디오의 Google Drive에 백업하는 도구(rclone ComMini)가 여기에 해당합니다. 이 도구들은 일반에 제공하는 서비스가 아니며 스튜디오 구성원 본인의 계정에만 연결됩니다.

1. 이용하는 정보

  • Google 계정으로 로그인할 때 받는 접근 토큰
  • 백업과 정리를 위해 읽고 쓰는 스튜디오 자신의 Google Drive 파일과 폴더 정보(이름, 크기, 수정일, 체크섬)

그 밖의 개인정보는 수집하지 않습니다.

2. 이용 목적

스튜디오 작업 파일을 Google Drive에 올리고, 올린 파일이 원본과 같은지 확인하고, Drive 안의 폴더를 정리하는 데에만 씁니다.

3. 보관과 제3자 제공

  • 접근 토큰은 스튜디오 작업 컴퓨터의 설정 파일에만 저장됩니다.
  • Drive 데이터는 스튜디오의 컴퓨터와 스튜디오 자신의 Google Drive 사이에서만 오갑니다.
  • 정보를 판매하거나 제3자에게 제공하지 않으며, 광고나 AI 모델 학습에 쓰지 않습니다.

4. Google API 데이터

Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 접근 권한 철회

Google 계정의 서드 파티 연결 관리에서 언제든 접근 권한을 철회할 수 있습니다. 철회하면 도구는 더 이상 Drive에 접근하지 못합니다.

This policy covers internal tools operated by A New Byeol Studio for its own work, such as a backup tool (rclone ComMini) that copies the studio's files to the studio's own Google Drive.
